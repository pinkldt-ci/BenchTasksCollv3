# Final Pool

This directory contains all implemented tasks from the BenchTasksCollv3 project.

Tasks are collected from developer branches when their implementation satisfies the requirements
outlined in `tasks/examples`.

## Status

No tasks have been implemented yet. All tasks are currently in "implementing" status.
Tasks will be added here as they meet the requirements:

1. `task_config.json` with non-empty `needed_mcp_servers` and `needed_local_tools` containing `claim_done`
2. `docs/task.md` non-empty and all English
3. `docs/agent_system_prompt.md` non-empty and all English
4. `docs/user_system_prompt.md` (if non-empty, must be all English)
5. `evaluation/main.py` exists
6. `preprocess/main.py` exists
7. `groundtruth_workspace/` exists
8. `initial_workspace/` exists
